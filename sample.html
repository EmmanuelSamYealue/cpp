C++ — Explained Like You're Five

Every idea below starts with a real-life picture. No prior experience needed. Read slowly, type every example, and don't worry about mistakes — they're part of learning.

📘 How to read this guide

Each section follows the same pattern: (1) a picture in your head, (2) the technical name, (3) a complete example, (4) a line-by-line walk-through, and (5) the mistake everyone makes. If a word confuses you, keep reading — it will be explained right after.

0. Getting Ready

🏠 Picture this

To bake a cake, you need two things: an oven and a kitchen to work in. In programming, the compiler is the oven (it turns your code into a running program) and the editor is the kitchen (where you type your code).

0.1 The Two Things You Need

0.2 Easiest Path for a Complete Beginner

  1. Go to codeblocks.org.
  2. Download the file whose name ends with mingw-setup.exe — this includes the compiler for you.
  3. Install it (just click Next, Next, Next).
  4. Open Code::Blocks. Click File → New → Empty File.
  5. Type the example below, save as hello.cpp.
  6. Press F9. Your program runs.

0.3 First Test

#include <iostream>
using namespace std;

int main() {
    cout << "It works!\n";
    return 0;
}
Output
It works!

If you see "It works!" — you're ready. If not, the problem is almost always installation, not your code. Reinstall using the mingw-setup.exe file.

1. What Is Programming?

🥪 Picture this

Imagine you're teaching a robot to make a peanut-butter sandwich. You can't just say "make a sandwich" — the robot has no idea what that means. You must say:

  1. Pick up a slice of bread.
  2. Open the peanut butter jar.
  3. Spread peanut butter on the bread.
  4. Put the second slice on top.

That numbered list is a program. The robot is the computer. The words you use to tell it (English, or in our case C++) is the programming language.

The computer is extremely literal. It does exactly what you say, in exactly the order you say. If you forget a step, it won't guess — it'll just fail. That's why programming needs care.

1.1 What Is C++?

C++ is a language for giving instructions to a computer. It was invented by Bjarne Stroustrup in 1979. It's used in video games (Fortnite), web browsers (Chrome), operating systems (Windows), self-driving cars, and much more.

Why people like it:

  • It's fast — one of the fastest languages that's still readable.
  • It gives you control over the computer's memory.
  • It runs on almost every device in the world.

1.2 What Happens When You Press "Run"?

This is important. Three things happen, in order:

  1. You write a .cpp file — plain text.
  2. The compiler reads it and translates it into machine language (1s and 0s) the CPU understands.
  3. The resulting program runs and does what you told it.
StepIf it goes wrong, the error looks like…
Preprocessing (bringing in files)fatal error: iostream: No such file
Compiling (checking your grammar)error: expected ';' before 'return'
Linking (joining pieces)undefined reference to 'add'
Running (executing)Crash, or wrong answer

1.3 Your First Program — Line by Line

#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!";
    return 0;
}
Output
Hello World!

Line 1: #include <iostream> — "Bring in the input/output toolbox." Without this, the computer has no idea what cout means.

Line 2: using namespace std; — "Use the standard toolbox without a long prefix." It's a convenience so you can write cout instead of std::cout.

Line 4: int main() — "Here is where the program starts." Every C++ program must have a main. When you run the program, the computer jumps here first.

Line 5: cout << "Hello World!"; — "Print this text on the screen." Think of cout as the screen, and << as an arrow pushing text into it.

Line 6: return 0; — "I finished successfully." A 0 means "no error". If something went wrong, you'd return a different number.

⚠️ The three mistakes every beginner makes
  • Wrong capital letter. cout is right. Cout and COUT are wrong. C++ is case-sensitive.
  • Missing semicolon. Every instruction ends with ; — like the period at the end of a sentence.
  • Missing main. No main function = nothing to run.

2. Printing Text

💬 Picture this

cout is like a loudspeaker. Whatever you put into it comes out on the screen. You put things in using the << arrows.

2.1 Printing Text vs Printing Numbers

Text goes in double quotes. Numbers do not.

// Correct: text has quotes, number doesn't
cout << "I am " << 25 << " years old.";
Output
I am 25 years old.

Why? Because "25" (with quotes) means "the characters 2 and 5" and 25 (without quotes) means "the number twenty-five". They look the same on screen but the computer treats them differently.

2.2 Making a New Line

If you print two things, they'll run together on the same line — like gluing two sentences with no space:

cout << "Hello";
cout << "World";
Output
HelloWorld

To push the next thing to a new line, use \n:

cout << "Hello\n";
cout << "World";
Output
Hello World

Or use endl (which means "end line"):

cout << "Hello" << endl;
cout << "World";

Both do the same thing. Most people use \n because it's shorter.

2.3 Other Useful Escape Sequences

Type thisYou get
\nGo to the next line
\tA tab (like 4 spaces)
\\A single backslash
\"A double quote inside quotes

Example with quotes and tabs:

cout << "Name\tAge\n";
cout << "Bob\t25\n";
cout << "She said \"hi\"\n";
Output
Name Age Bob 25 She said "hi"

2.4 Comments — Notes to Yourself

Comments are text the computer ignores. Use them to explain what your code does.

// This is a comment — one line

/* This is also a comment
   but it can span
   multiple lines */
💡 What makes a good comment?

Write why, not what. The code already says what it does.

❌ // add one to x — useless, we can see that.

✅ // retry once because the sensor sometimes fails — useful!

3. Variables — Named Boxes

🫙 Picture this

Imagine a row of jars on a shelf. Each jar has a label written on it ("sugar", "flour", "salt") and something inside. A variable is exactly like that:

  • The label = the variable's name (age)
  • The contents = the variable's value (25)
  • The type of jar = the variable's type (int, string, etc.)

A jar labelled "sugar" only holds sugar — not milk. In the same way, a variable of type int can only hold whole numbers.

3.1 Making a Variable (Declaring It)

The pattern is always: type, then name, then value.

int age = 25;

int — "I want a box that holds whole numbers."

age — "Label this box 'age'."

= 25 — "Put the number 25 inside."

; — "End of instruction."

3.2 The 5 Types You Need

TypeHoldsExample
intWhole numbersint age = 25;
doubleDecimalsdouble price = 19.99;
charOne character (in single quotes)char grade = 'A';
stringText (in double quotes)string name = "Alice";
booltrue or falsebool isReady = true;
⚠️ Single quotes vs double quotes — they are NOT the same

'A' (single quotes) = one char.

"A" (double quotes) = a string (text) that happens to have one letter.

Mixing them up causes compile errors. Remember: char = one character = single quotes.

3.3 Using a Variable

int age = 25;
cout << "Age is " << age;
Output
Age is 25

See? You put age (the label) into cout, and the computer looks up what's inside and prints it.

3.4 Changing What's Inside

int score = 10;
score = 50;              // old value 10 is thrown away
cout << score;            // prints 50

The = sign is not "equals" like in math — it means "put this in the box". So score = 50 means "empty out score and put 50 in it".

3.5 Constants — Boxes That Can't Change

Sometimes you want a value that never changes. Use const:

const double PI = 3.14159;
PI = 3.0;   // ✗ ERROR — cannot change a constant
📜 Picture this

const is like a value written in permanent marker — it's on the jar and can never be changed. Use it for true facts that won't change, like the number of minutes in an hour (60), or the value of PI.

3.6 Naming Your Variables

Rules:

  • Start with a letter or underscore: age, _count.
  • Cannot start with a number: 2age ❌
  • No spaces or symbols: my age ❌, my_age ✅
  • Case matters: Age and age are two different boxes.

Good names are descriptive. Prefer studentAge over x.

3.7 Putting It All Together

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "Alice";
    int    age  = 25;
    double height = 1.68;
    char   grade = 'A';

    cout << name << " is " << age << " years old.\n";
    cout << "Height: " << height << "m, grade " << grade << "\n";
    return 0;
}
Output
Alice is 25 years old. Height: 1.68m, grade A

4. Asking the User for Input

🎤 Picture this

cout is your program's mouth (it speaks to the user). cin is its ear (it listens to the user). When you type on the keyboard, cin catches what you typed and stores it in a variable.

4.1 Reading a Number

int age;
cout << "How old are you? ";
cin  >> age;
cout << "You are " << age << " years old.\n";
Example run
How old are you? 25 You are 25 years old.

int age; — "Make an empty box called age."

cin >> age; — "Listen to the keyboard, and put whatever number the user types into the box called age."

The arrows >> point into the variable — think "the user's typing flows into age".

4.2 Reading a Whole Line of Text

Careful! cin >> stops at the first space. It reads one word, not a whole sentence.

string name;
cout << "Full name? ";
cin  >> name;
If you type "John Smith"
You typed: John

The "Smith" part gets lost! To read the whole line, use getline:

string name;
cout << "Full name? ";
getline(cin, name);   // reads the WHOLE line, spaces included
cout << "Hello, " << name << "!\n";
If you type "John Smith"
Hello, John Smith!

4.3 A Complete Example

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int    age;

    cout << "Your name: ";
    getline(cin, name);

    cout << "Your age: ";
    cin >> age;

    cout << "Hello " << name << "! You are " << age << ".\n";
    return 0;
}
Example run
Your name: John Smith Your age: 25 Hello John Smith! You are 25.
⚠️ The trickiest bug in beginner C++

If you use cin >> number; and then getline(cin, text); right after, getline reads an empty line. Why? Because cin >> leaves the "Enter key press" (newline) in the buffer, and getline thinks that's your input.

Fix: put cin.ignore(); between them.

cin >> age;
cin.ignore();   // eat the leftover newline
getline(cin, name);

5. Math in C++

🧮 Picture this

C++ is a very good calculator. You can do all the basic math with the usual symbols — plus a couple of special ones.

5.1 The Basic Operators

SymbolMeaningExampleResult
+Add3 + 58
-Subtract10 - 46
*Multiply6 * 742
/Divide20 / 45
%Remainder10 % 31

5.2 The Integer Division Trap

⚠️ Whole numbers ÷ whole numbers = whole number

If both sides of / are int, the decimal part is thrown away (not rounded).

int a = 10;
int b = 3;
cout << a / b;   // prints 3, not 3.33

The computer does 10 / 3 = 3, then stops. It doesn't know what to do with the "1 leftover" unless you ask.

Fix: make at least one side a decimal:

double a = 10.0;
double b = 3.0;
cout << a / b;   // prints 3.33333

5.3 The Remainder Operator (%)

% gives you what's left over after division. Useful for:

  • Checking even/odd: n % 2 == 0 means even.
  • Cycling through a list: i % 5 always gives 0, 1, 2, 3, 4, 0, 1…
  • Getting last digit: n % 10.
cout << 10 % 3;   // 1 (because 3 goes into 10 three times, with 1 left over)

5.4 Increment and Decrement

++ means "add 1". -- means "subtract 1".

int x = 5;
x++;                // x is now 6
x++;                // x is now 7
x--;                // x is now 6

5.5 Shortcut Operators

You'll often want to add to a variable. Two ways to do the same thing:

x = x + 5;    // long way
x += 5;       // shortcut

Same for -=, *=, /=, %=.

5.6 Comparing Values

OperatorAsksExampleAnswer
==Are they equal?5 == 5true
!=Are they different?5 != 5false
>Greater than?7 > 3true
<Less than?7 < 3false
>=Greater or equal?5 >= 5true
<=Less or equal?5 <= 3false
⚠️ = vs ==

= means put something in the box (assignment).

== means are these equal? (comparison).

if (x = 5)    // ✗ WRONG — puts 5 into x, then x is "true"
if (x == 5)   // ✓ CORRECT — checks if x equals 5

5.7 Order of Operations

Same as in math class: * and / before + and -. When in doubt, use parentheses.

cout << 2 + 3 * 4;     // 14 (multiplication first)
cout << (2 + 3) * 4;   // 20 (parentheses first)

6. Text (Strings)

📝 Picture this

A string is a chain of characters — like a train where each car holds one letter. In C++ you write strings inside double quotes: "Hello".

6.1 Making and Using a String

#include <string>
using namespace std;

string greeting = "Hello";
cout << greeting;   // prints Hello

6.2 Joining Strings Together

Use + to glue strings:

string first = "John";
string last  = "Smith";
string full  = first + " " + last;
cout << full;     // prints John Smith
⚠️ Number + String = error
string name = "Age: ";
int    age  = 25;
cout << name + age;    // ✗ ERROR

You can't add text and numbers directly. Convert the number to text first:

cout << name + to_string(age);   // ✓ works

6.3 Length of a String

string word = "Hello";
cout << word.length();   // 5
cout << word.size();     // 5 (same thing)

6.4 Looking at One Letter

Strings are numbered starting at 0. So the first character is [0].

string word = "Hello";
//                01234
cout << word[0];   // H
cout << word[1];   // e
cout << word[4];   // o

6.5 Changing a Letter

string word = "Hello";
word[0] = 'J';
cout << word;   // Jello
💡 Safety note

Asking for word[100] on a 5-letter string won't crash — it'll just read junk (undefined behavior). Use word.at(100) instead, which will throw a clear error.

6.6 Reading Text With Spaces

We covered this in Section 4 — remember: cin >> stops at spaces. Use getline(cin, name) to read a whole sentence.

7. Making Decisions (if / else)

🚦 Picture this

You make decisions all day: "If it's raining, I'll take an umbrella. Otherwise, I won't." That's exactly what if and else do in code.

7.1 Basic if

int age = 20;

if (age >= 18) {
    cout << "You can vote.\n";
}
Output
You can vote.

if — "Check this question."

(age >= 18) — "Is age at least 18?"

{ ... } — "If yes, do everything inside the curly braces."

If the answer is no, the whole block gets skipped.

7.2 if + else

int age = 15;

if (age >= 18) {
    cout << "You can vote.\n";
} else {
    cout << "You are too young.\n";
}
Output
You are too young.

"If yes → do the first block. Otherwise → do the else block." Exactly one of the two runs, never both.

7.3 else if — More Than Two Choices

int score = 85;

if (score >= 90) {
    cout << "Grade A\n";
} else if (score >= 80) {
    cout << "Grade B\n";
} else if (score >= 70) {
    cout << "Grade C\n";
} else {
    cout << "Grade F\n";
}
Output
Grade B
⚠️ Order matters!

The computer checks each condition in order and stops at the first one that's true. If you checked score >= 70 first, then a score of 95 would get "Grade C" — and "Grade A" would never be reached.

Rule: check from most restrictive to least.

7.4 The Short Way: ?:

For simple "if this, then X, else Y", there's a one-line version:

string result = (age >= 18) ? "adult" : "minor";

Read it as: "If age ≥ 18, then 'adult', else 'minor'."

7.5 Combining Conditions

&& = "and" (both must be true).
|| = "or" (at least one must be true).
! = "not" (reverse the answer).

if (age >= 18 && hasID) {
    cout << "You can enter.\n";
}
if (day == "Sat" || day == "Sun") {
    cout << "It's the weekend!\n";
}

7.6 A Real Example — Voting With ID

int age = 20;
bool hasID = true;

if (age >= 18) {
    if (hasID) {
        cout << "You can vote.\n";
    } else {
        cout << "You need ID.\n";
    }
} else {
    cout << "You are too young.\n";
}

8. Menu Choices (switch)

🍔 Picture this

At a fast-food counter, you say a number: "Number 1, please." The cashier looks up the menu: 1 = burger, 2 = chicken, 3 = salad. That's exactly what switch does — it picks one option from a list.

8.1 The Basic Form

int choice = 2;

switch (choice) {
    case 1:
        cout << "You ordered a burger.\n";
        break;
    case 2:
        cout << "You ordered chicken.\n";
        break;
    case 3:
        cout << "You ordered salad.\n";
        break;
    default:
        cout << "That's not on the menu.\n";
}
Output
You ordered chicken.

switch (choice) — "Look at the value of choice."

case 1: — "If it's 1, do this."

break; — "Stop here. Don't keep checking other cases."

default: — "If nothing matched, do this." (Optional but good.)

⚠️ Don't forget break!

Without break, the computer keeps running the next case too. This is called fall-through and it's usually a bug.

case 1:
    cout << "one ";
    // no break here
case 2:
    cout << "two ";
    break;

If choice == 1, you'd see "one two". Usually not what you want.

8.2 When to Use switch vs if/else

Use switch when…Use if/else when…
Comparing one value to exact numbers/lettersComparing with >, <, >=
Building a menuCombining conditions with && or ||
Checking against several specific optionsComplex logic

9. Repeating Things (Loops)

🔁 Picture this

If a recipe says "stir 20 times", you don't write "stir" 20 times on paper — you write it once and mark "repeat 20 times". A loop is the same idea: do this block of code again and again.

9.1 The while Loop — "Keep Going While…"

int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}
Output
1 2 3 4 5

"Set i to 1."

"While i is ≤ 5, do the block."

Block: print i, then add 1 to i.

Once i becomes 6, the condition is false and the loop stops.

⚠️ Don't forget i++!

If you remove i++, i stays at 1 forever. The condition is always true. The program runs forever — an infinite loop. You'll have to force-quit the program.

9.2 The for Loop — "Repeat N Times"

When you know how many times to repeat, for is cleaner:

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
Output
1 2 3 4 5

for (start; condition; step) — three parts in one line.

start: int i = 1; — happens once at the beginning.

condition: i <= 5 — checked before each pass; stop when false.

step: i++ — happens after each pass.

9.3 The do-while Loop — "Do It Once, Then Check"

This loop always runs at least once, then asks "should I run again?"

int i = 10;
do {
    cout << "Ran once!\n";
} while (i < 5);   // condition is false, but it still ran once
Output
Ran once!
💡 When to use do-while?

When you want to run something at least once no matter what — like showing a menu before asking the user if they want to quit.

9.4 The Range-Based for — "For Each Item in the List"

Super clean way to walk through an array or vector:

int numbers[3] = {10, 20, 30};

for (int n : numbers) {
    cout << n << " ";
}
Output
10 20 30

Read as: "For each int n in numbers, print n."

9.5 Stopping a Loop Early

  • break; — leave the loop immediately.
  • continue; — skip the rest of this pass, jump to the next one.
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;       // stop when i reaches 5
    cout << i << " ";
}
Output
1 2 3 4
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;    // skip 3
    cout << i << " ";
}
Output
1 2 4 5

9.6 Nested Loops — Loops Inside Loops

Imagine a clock. The minute hand goes around 60 times while the hour hand moves once. That's a loop inside a loop.

for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 3; col++) {
        cout << row * col << " ";
    }
    cout << "\n";
}
Output
1 2 3 2 4 6 3 6 9

10. Lists of Things (Arrays & Vectors)

📦 Picture this

You don't keep 30 separate jars for your coins — you keep one jar full of coins. Similarly, an array (or its flexible cousin, a vector) is a numbered row of boxes all holding the same type of thing.

10.1 Making an Array

int scores[5] = {90, 85, 77, 92, 88};

int scores[5] — "Make 5 boxes of type int, all with one name: scores."

= {90, 85, ...} — "Put these values inside."

10.2 Accessing Items by Number

Like strings, arrays are numbered starting at 0.

int scores[5] = {90, 85, 77, 92, 88};
//                   0     1     2     3     4

cout << scores[0];   // 90
cout << scores[4];   // 88

10.3 Changing an Item

scores[0] = 100;   // now the first is 100

10.4 Looping Over an Array

int scores[5] = {90, 85, 77, 92, 88};

for (int i = 0; i < 5; i++) {
    cout << scores[i] << "\n";
}
⚠️ Never go past the end!

If an array has 5 items (indexes 0–4), scores[5] or scores[100] is undefined behavior — reading or writing garbage. C++ won't warn you, and it might crash your program or corrupt other data.

This kind of bug has caused serious security holes in real software. Always check your bounds.

10.5 Vectors — Arrays That Grow

A vector is like an array that can grow or shrink. Most modern C++ code uses vectors instead of raw arrays because they're safer and more flexible.

#include <vector>

vector<int> scores = {90, 85, 77};

scores.push_back(100);   // add to the end
scores.pop_back();     // remove the last one

cout << scores.size();    // 3
cout << scores[0];       // 90
ArrayVector
Fixed size — declared once, never changesGrows automatically
Faster (no management cost)Slightly slower, much more flexible
Recommended for beginners? NoYes — use this by default

10.6 Looping Over a Vector

for (int n : scores) {
    cout << n << " ";
}

11. Reusable Recipes (Functions)

🍳 Picture this

Imagine writing out the full steps to make coffee every single morning — over and over. Pointless. Instead, you write it once on a recipe card called "makeCoffee". Each morning you just say "make coffee".

A function is a recipe card for your code. You write the steps once, give it a name, and then just use the name whenever you need it.

11.1 Making a Function

int add(int a, int b) {
    return a + b;
}

int — "This function will give back a whole number." (The return type.)

add — "The function's name."

(int a, int b) — "It needs two whole numbers to do its job." (These are the parameters.)

return a + b; — "The answer is a + b. Hand it back to whoever called me."

11.2 Using (Calling) the Function

int result = add(3, 4);
cout << result;   // 7

"Hey add, here's 3 and 4 — do your thing." The function returns 7, and we store it in result.

11.3 A Function That Doesn't Return Anything

Some functions just do something (print, save) without giving a value back. Use void:

void greet(string name) {
    cout << "Hello, " << name << "!\n";
}

greet("Alice");   // Hello, Alice!

11.4 Pass by Value vs Pass by Reference

📄 Picture this

You have a document. You can either:

  • Hand over a photocopy — the other person can scribble on it, but your original is untouched.
  • Hand over the original — whatever they write goes straight onto your document.

These are the two ways to pass values to functions.

void writeOnCopy(int x)  { x = 999; }    // copy
void writeOriginal(int& x) { x = 999; }    // original (&)

int score = 10;
writeOnCopy(score);   // score is still 10
writeOriginal(score); // score is now 999

The & means "reference" — pass the original, not a copy.

11.5 Why Functions Are Great

  • Write once, use many times.
  • Easier to read — calculateTax(price) is clearer than 10 lines of math.
  • Easier to fix — change the recipe in one place, everything updates.

11.6 A Complete Example

#include <iostream>
using namespace std;

int square(int x) { return x * x; }
int cube(int x)   { return x * x * x; }

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << " squared: " << square(i)
             << ", cubed: "  << cube(i) << "\n";
    }
}
Output
1 squared: 1, cubed: 1 2 squared: 4, cubed: 8 3 squared: 9, cubed: 27 4 squared: 16, cubed: 64 5 squared: 25, cubed: 125

11.7 Recursion — A Function That Calls Itself

Sometimes a problem is naturally self-similar. Factorial of 5 is 5 × 4 × 3 × 2 × 1. Notice: factorial(5) = 5 × factorial(4).

int factorial(int n) {
    if (n == 1) return 1;      // base case — STOP calling
    return n * factorial(n - 1);    // recursive step
}

cout << factorial(5);   // 120
⚠️ Every recursion needs a base case

If the function never stops calling itself, the computer runs out of memory and crashes (stack overflow). The base case tells it when to stop.

12. Addresses (Pointers)

🏠 Picture this

Your friend asks where you live. You could:

  • Give them your whole house (impractical), or
  • Give them your address — a note saying "go to 123 Main St".

A pointer is like that address note. It doesn't hold the value itself — it holds the location of the value. Just like a note in your pocket saying "the sugar is on shelf 3".

12.1 Getting an Address

Every variable lives somewhere in memory. You can find out where using &:

int age = 25;
cout << &age;   // prints something like 0x7ffe5d

12.2 Storing an Address in a Pointer

int age = 25;
int *p = &age;    // p holds the address of age

int* — "p is a pointer to an int." (The * is part of the type.)

&age — "The address of age."

12.3 Reading the Value Through the Pointer

cout << *p;   // prints 25

The * here means "go to the address and give me what's there". This is called dereferencing.

12.4 Changing a Value Through a Pointer

*p = 30;
cout << age;   // now prints 30

12.5 References — The Nicer Alternative

A reference is like a second name for the same variable. Easier than pointers for most cases.

int age = 25;
int &alias = age;   // alias IS age, same box

alias = 30;
cout << age;         // 30
⚠️ For beginners: don't overuse pointers

Pointers are powerful but easy to misuse. For now, the golden rule is:

  • Use std::vector instead of raw arrays.
  • Use references (&) instead of pointers for function parameters.
  • Never write new or delete unless you must — use std::make_unique instead.

12.6 Smart Pointers — The Safe Way

Modern C++ gives you "smart pointers" that clean up their memory automatically, so you can never forget.

#include <memory>

{
    auto p = std::make_unique<int>(42);
    cout << *p << "\n";   // 42
}   // memory freed automatically here

13. Blueprints (Object-Oriented Programming)

🍪 Picture this

A cookie cutter is just a shape — it's not a cookie. But you can make many cookies with it. In C++:

  • Class = the cookie cutter (the blueprint).
  • Object = an actual cookie made from the cutter.

Writing class Car { ... } doesn't make a car — it makes a template for cars. You actually build one with Car myCar;.

13.1 Your First Class

class Rectangle {
public:
    int width;
    int height;

    int area() {
        return width * height;
    }
};

int main() {
    Rectangle r;
    r.width = 5;
    r.height = 3;
    cout << r.area();   // 15
}

class Rectangle { ... }; — "Make a blueprint for rectangles." (Note the semicolon at the end!)

public: — "These parts can be used outside the class."

int width; — "Every rectangle has a width."

int area() { ... } — "Every rectangle can calculate its area."

Rectangle r; — "Make an actual rectangle and call it r."

r.width = 5; — "Use a dot to access the box inside the object."

13.2 Public vs Private

KeywordWho can use it
publicAnyone (from outside the class)
privateOnly the class itself
protectedThis class + classes that inherit from it

Best practice: make data private and provide public functions to read/change it safely. This is called encapsulation.

13.3 Constructors — Running Code at Creation

A constructor is a special function that runs automatically when you create an object. It's for setting up the object's starting state.

class Rectangle {
public:
    int width, height;

    Rectangle(int w, int h) {   // constructor
        width = w;
        height = h;
    }

    int area() { return width * height; }
};

Rectangle r(5, 3);   // constructor runs, r is ready to use
cout << r.area();    // 15

13.4 Destructors — Cleaning Up

A destructor runs automatically when an object is destroyed. Use it to free resources (close a file, release memory). It has the same name as the class, prefixed with ~.

class File {
public:
    File()  { cout << "File opened\n"; }
    ~File() { cout << "File closed\n"; }
};

This auto-cleanup pattern is called RAII — one of C++'s most important ideas. You don't have to remember to close anything; the destructor does it.

13.5 Inheritance — Building on Another Class

If you have a "Vehicle" class, then "Car" and "Bike" are both vehicles. Inheritance lets them share code.

class Animal {
public:
    void eat() { cout << "Eating...\n"; }
};

class Dog : public Animal {
public:
    void bark() { cout << "Woof!\n"; }
};

Dog d;
d.eat();    // inherited from Animal
d.bark();   // Dog's own

Read class Dog : public Animal as "Dog is a kind of Animal." Dog gets everything Animal has, plus its own stuff.

13.6 A Complete Class Example — Bank Account

class BankAccount {
private:
    string owner;
    double balance;

public:
    BankAccount(string name, double start) {
        owner = name;
        balance = start;
    }

    void deposit(double amount) {
        if (amount <= 0) {
            cout << "Invalid deposit.\n";
            return;
        }
        balance += amount;
    }

    void show() const {
        cout << owner << " has $" << balance << "\n";
    }
};

int main() {
    BankAccount acc("Alice", 100.0);
    acc.deposit(50.0);
    acc.show();      // Alice has $150
}

14. Modern C++ — The Nice Additions

14.1 auto — Let the Compiler Guess

You don't always have to spell out the type. Let C++ figure it out:

auto x = 5;              // int
auto y = 3.14;           // double
auto s = "hello";        // const char*
auto b = true;             // bool

Convenient for complicated types. For simple ones, writing the type is often clearer.

14.2 enum class — Named Choices

Instead of using strings or numbers for states, use a small set of named values:

enum class Color { Red, Green, Blue };

Color c = Color::Red;
if (c == Color::Red) cout << "Red!\n";

14.3 Lambdas — Tiny Inline Functions

For quick one-off functions, C++ lets you write it right where you use it:

auto square = [](int x) { return x * x; };
cout << square(5);   // 25

14.4 Range-Based for — Already Seen

Your best friend for iterating:

for (int n : numbers) { /* do something with n */ }

14.5 constexpr — Compute at Compile Time

If a value can be known when you compile the program, why wait until it runs?

constexpr int SIZE = 10;
int arr[SIZE];   // valid — compiler knows the size

15. Files & Errors

15.1 Throwing and Catching Errors

🚨 Picture this

An exception is like a fire alarm. When something goes wrong, the program "raises the alarm". A try/catch is your fire department, ready to handle it. If nobody catches it, the program crashes.

#include <stdexcept>

double divide(double a, double b) {
    if (b == 0) throw std::invalid_argument("Cannot divide by zero");
    return a / b;
}

int main() {
    try {
        cout << divide(10, 0) << "\n";
    }
    catch (const std::invalid_argument& e) {
        cout << "Error: " << e.what() << "\n";
    }
}
Output
Error: Cannot divide by zero

15.2 Writing to a File

#include <fstream>

ofstream out("notes.txt");
if (!out) {
    cout << "Could not open file!\n";
    return 1;
}
out << "Hello, file!\n";
out << "Second line.\n";
out.close();

15.3 Reading from a File

ifstream in("notes.txt");
string line;
while (getline(in, line)) {
    cout << line << "\n";
}
⚠️ Always check if a file opened

If the file doesn't exist or you don't have permission, the program silently fails. Check if (!out) before using the file.
