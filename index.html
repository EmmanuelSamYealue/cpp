📘 How to read a compiler error

Compiler messages look intimidating but are formulaic:

file.cpp:LINE:COL: error: MESSAGE
  • file.cpp — which file contains the problem
  • LINE — line number. Read the line before it too; missing semicolons are reported on the next line.
  • error: — prevents compilation. warning: — legal but suspicious. Treat warnings as errors during development.

1. Introduction to C++

1.1 What Is Programming?

Programming is the process of giving instructions to a computer in a language it can understand. A program is a set of ordered steps used to solve a problem; an algorithm is the abstract logic behind it. The programming language is simply the notation you use to communicate the algorithm to the machine.

Three skills matter, in this order:

  1. Problem decomposition — breaking a big problem into small steps.
  2. Algorithmic thinking — expressing those steps precisely (loops, conditions, data).
  3. Syntax — the grammar of the specific language. This is the easiest part, and the part beginners over-focus on.

1.2 What Is C++?

C++ was created by Bjarne Stroustrup at Bell Labs starting in 1979, originally as "C with Classes." It is a cross-platform, compiled, statically typed, multi-paradigm language: it supports procedural programming (like C), object-oriented programming, generic programming (templates), and functional-style techniques. It gives programmers a high level of control over system resources and memory.

1.3 Why Use C++?

  • Performance: Zero-cost abstractions — high-level constructs compile down to near-handwritten machine code.
  • Deterministic memory management: You decide when memory is allocated and freed (RAII makes this safe).
  • Portability: Compilers exist for virtually every CPU and OS; the language is portable across multiple platforms.
  • Object-oriented: Gives a clear structure to programs and allows code to be reused, lowering development costs.
  • Strong fundamentals: Teaches memory management, how computers work, and supports both procedural and OOP styles.
  • Huge ecosystem: Decades of libraries, engines, and tooling.
  • Close to C, C#, and Java: Makes it easy for programmers to switch between these languages.

1.4 Difference Between C and C++

C++ was developed as an extension of C, and both languages have almost the same syntax. The main difference is that C++ supports classes and objects, while C does not. This single addition — object-oriented programming — is what gives C++ its name and its power for large systems.

🌍 Real-World Perspective

When you launch Fortnite, the Unreal Engine rendering tens of millions of triangles per second is C++. When a trading firm executes an order in 8 microseconds, that path is C++. When Photoshop filters a 500-megapixel image, the pixel loops are C++. The reason is always the same: predictable, low-level control over memory and CPU.

1.6 Your First Program, Line by Line

📘 Structure of a C++ program

Every C++ program has four parts: header files (like <iostream>), the main() function, statements, and a return value. Understanding these four parts is the key to reading any C++ source file.

1.7 Compiling It

# GCC / Clang
g++ -std=c++17 -Wall -Wextra -O2 myfirstprogram.cpp -o app
./app

# MSVC
cl /EHsc /std:c++17 myfirstprogram.cpp
app.exe
💡 Always compile with warnings enabled

-Wall -Wextra (GCC/Clang) or /W4 (MSVC) turns on warnings that catch real bugs: unused variables, signed/unsigned mismatches, uninitialized values. Treat warnings as errors during development: -Werror.

⚠️ Three rules that break beginners most often
  • Case sensitivity: cout, Cout, and COUT are three different identifiers. Only the first exists. Similarly, if is lowercase; If or IF will generate an error.
  • Semicolons: Every statement ends with ;. #include lines, function definitions, and block braces do not. Forgetting a semicolon produces error: expected ';' before 'return'.
  • White space: The compiler ignores white spaces. However, multiple lines make the code more readable.

2.2 Statements — One Instruction at a Time

A computer program is a list of "instructions" to be "executed" by a computer. In a programming language, these instructions are called statements. This statement "instructs" the compiler to print the text "Hello World" to the screen:

cout << "Hello World!";   // ✓ semicolon ends the statement

It is important that you end the statement with a semicolon ;. If you forget it, an error will occur and the program will not run:

cout << "Hello World!"    // ✗ error: expected ';' before 'return'

Most C++ programs contain many statements. The statements are executed one by one, in the same order as they are written:

cout << "Hello World!";
cout << "Have a good day!";
return 0;
Output
Hello World!Have a good day!

Notice that the two outputs run together with no space or newline between them — because neither statement adds a line break. This is the #1 reason beginners wonder why their output looks squashed. We fix this in the next section.

2.3 Printing Output with cout — Text

The cout object, together with the << operator, is used to output values and print text. Just remember to surround the text with double quotes ("):

#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!";
    return 0;
}
Output
Hello World!

You can add as many cout objects as you want. However, note that it does not insert a new line at the end of the output — as the previous section showed. You can also chain multiple values in a single statement:

int    age   = 25;
double price = 19.99;
string name  = "Alice";

cout << "Name: " << name
     << " | Age: " << age
     << " | Price: " << price << endl;
Output
Name: Alice | Age: 25 | Price: 19.99

2.4 Printing Numbers

You can also use cout to print numbers. However, unlike text, we do not put numbers inside double quotes:

#include <iostream>
using namespace std;

int main() {
    cout << 3;
    return 0;
}
Output
3

You can also perform mathematical calculations directly inside cout:

cout << 3 + 3;   // prints 6
cout << 2 * 5;   // prints 10
Output
610

Notice both numbers run together because there is no newline between them. The next section fixes this.

2.5 New Lines

To insert a new line in your output, you can use the \n character:

cout << "Hello World! \n";
cout << "I am learning C++";
Output
Hello World! I am learning C++

You can also use another << operator and place the \n character after the text, like this:

cout << "Hello World!" << "\n";
cout << "I am learning C++";
💡 Two \n characters create a blank line
cout << "Hello World!" << "\n\n";
cout << "I am learning C++";
Output
Hello World! I am learning C++

Another way: the endl manipulator

Another way to insert a new line is with the endl manipulator:

cout << "Hello World!" << endl;
cout << "I am learning C++";

Both \n and endl break lines. However, \n is most used. The key difference is that endl also flushes the output buffer, forcing an immediate write to the OS — useful before interactive prompts but slower in loops.

But what is \n exactly? The newline character (\n) is called an escape sequence, and it forces the cursor to change its position to the beginning of the next line on the screen. This results in a new line.

2.7 Namespaces — Why They Exist

Large projects inevitably produce name collisions: your print() and a library's print(). Namespaces create scopes for names. Every standard library name lives inside the std namespace.

namespace geometry {
    double area(double r) { return 3.14159 * r * r; }
}

namespace finance {
    double area(double r) { return r * r; }
}

int main() {
    cout << geometry::area(2) << "\n"; // 12.5664
    cout << finance::area(2)  << "\n"; // 4
}

Omitting the namespace

You might see some C++ programs that run without the using namespace std; line. The line can be omitted and replaced with the std keyword, followed by the :: operator for objects:

#include <iostream>
// using namespace std;  ← removed

int main() {
    std::cout << "Hello World!";
    return 0;
}

It is up to you whether you include the standard namespace library or not. For small programs, using namespace std; is convenient. For larger code, prefer explicit std:: qualification.

⚠️ Never put using namespace std; in a header file

Header files get pasted into every file that includes them. A using namespace std; in a header silently pollutes the namespace of the entire project — and can create name clashes with std::count, std::distance, std::swap, and more. Keep it inside .cpp files only.

2.8 Comments

Comments can be used to explain C++ code, and to make it more readable. They can also be used to prevent execution when testing alternative code. Comments can be single-lined or multi-lined.

Single-line comments

Single-line comments start with two forward slashes (//). Any text between // and the end of the line is ignored by the compiler (will not be executed).

// This is a comment
cout << "Hello World!";

cout << "Hello World!"; // This is also a comment

Multi-line comments

Multi-line comments start with /* and end with */. Any text between them will be ignored by the compiler.

/* The code below will print the words Hello World!
   to the screen, and it is amazing */
cout << "Hello World!";

It is up to you which you want to use. Normally, we use // for short comments and /* */ for longer ones.

Write comments that explain why, not what. The code already says what it does.

// BAD: restates the code
x = x + 1; // add one to x

// GOOD: explains intent
// Retry once because the sensor occasionally returns a stale reading
reading = readSensor();

3. Variables & Data Types

3.1 The Mental Model: Named Boxes in Memory

Variables are containers for storing data values. A variable is a named storage location used to store data. Every variable is a named region of memory that holds a value of a specific type. The type does two jobs:

  1. It decides how many bytes are reserved (a jar's size).
  2. It decides how those bytes are interpreted (is the jar labelled "paint" or "juice"?).

A char and an int both store numbers internally, but a char is displayed as a letter and an int as a number. The bytes in memory are just bytes — the type decides how to read them.

📘 Think of it like… a set of labelled jars
  • A label → the variable name (age)
  • A size → determined by the type (int = 4 bytes)
  • Contents → the current value (25)
  • A shape → the type says what fits. You cannot pour "hello" into an int jar — the compiler refuses.
Figure 2 — Variables are typed slots in memory. int age stores 25 as raw bytes; char grade stores 'A' as ASCII code 65.

3.3 Declaring (Creating) Variables

To create a variable, specify the type and assign it a value:

type variableName = value;

Where type is one of the C++ types (such as int), and variableName is the name of the variable. The equal sign assigns the value.

Create a variable called myNum of type int and assign it the value 15:

int myNum = 15;
cout << myNum;
Output
15

You can also declare a variable without assigning a value, and assign it later:

int myNum;       // declaration
myNum = 15;      // assignment
cout << myNum;
Output
15

Changing variable values: if you assign a new value to an existing variable, it will overwrite the previous value:

int myNum = 15;    // myNum is 15
myNum = 10;        // Now myNum is 10
cout << myNum;      // Outputs 10

3.4 Displaying Variables

The cout object, together with the << operator, is used to display variables. To combine both text and a variable, separate them with the << operator:

int myAge = 35;
cout << "I am " << myAge << " years old.";
Output
I am 35 years old.

You can also combine different types:

string name   = "John";
int    age    = 35;
double height = 6.1;

cout << name << " is " << age << " years old and "
     << height << " feet tall.";
Output
John is 35 years old and 6.1 feet tall.

3.5 Adding Variables Together

int x = 5;
int y = 6;
int sum = x + y;
cout << sum;
Output
11

3.6 Declaring Many Variables

To declare more than one variable of the same type, use a comma-separated list:

int x = 5, y = 6, z = 50;
cout << x + y + z;
Output

One value to multiple variables: you can assign the same value to multiple variables in one line:

int x, y, z;
x = y = z = 50;

Output
150

3.7 Identifiers — Naming Your Variables

All C++ variables must be identified with unique names. These unique names are called identifiers. Identifiers can be short names (like x and y) or more descriptive names (age, sum, totalVolume).

Rules for naming identifiers

  • Must begin with a letter or underscore (_).
  • Cannot begin with a number.
  • Can contain letters, digits, and underscores.
  • Names are case-sensitive (myVar and myvar are different variables).
  • Cannot contain whitespace or special characters like !, #, %, etc.
  • Cannot use reserved keywords (like int, return, class) as names.
  • Should be meaningful.
// Good — descriptive
int studentName;
int totalMarks;
int courseCode;
int minutesPerHour = 60;

// OK, but not easy to understand what m actually is
int m = 60;

It is recommended to use descriptive names to create understandable and maintainable code. This course uses simplified names like myNum or myChar in examples to match their type, but in real code, use names that describe what the data means.

3.8 Constants — Values That Never Change

A constant is a value that does not change during program execution. When you do not want others (or yourself) to change existing variable values, use the const keyword — this declares the variable as "constant," meaning unchangeable and read-only:

const double PI = 3.14159;
const int    MINUTES_PER_HOUR = 60;

// PI = 3.14;  // ✗ error: assignment of read-only variable 'PI'

You should always declare a variable as constant when you have values that are unlikely to change:

const int myNum = 15;   // myNum will always be 15
myNum = 10;            // ✗ error: assignment of read-only variable
⚠️ A constant must be assigned a value when declared
// ✓ Like this

// ✗ This will NOT work

minutesPerHour = 60;   // error

The compiler needs the value at the point of declaration, so it can enforce the "never changes" rule from the very first moment the variable exists.

constexpr is stronger: it guarantees the value is computable at compile time.

3.13 ASCII — The Character Phonebook

What is ASCII?

ASCII (American Standard Code for Information Interchange) is a character encoding standard that maps characters (letters, digits, punctuation, control codes) to numeric codes. Think of ASCII as a phonebook that links characters to numbers. Computers don't understand letters directly — they store numbers. ASCII is one of the oldest and simplest rules for which number means which character.

The basic idea

ASCII maps characters → numbers (codes), using codes from 0 to 127:

  • 'A' → 65
  • 'a' → 97
  • '0' → 48
  • space → 32

So when you type A, the computer stores the number 65 (one byte), and when it sees 65 it knows to show A.

3.15 The auto Keyword

The auto keyword automatically detects the type of a variable based on the value you assign to it. It helps you write cleaner code and avoid repeating types, especially for long or complex types. Starting in C++11, auto became a powerful way to let the compiler figure out the type.

In simple cases, use int, double, and other basic types when the type is easy to see. For more complex types — like iterators and lambdas — auto keeps the code cleaner.

4.4 The Classic Space Bug: cin >> vs getline

cin >> reads only one word. It considers a space (whitespace, tabs, etc.) as a terminating character, so it can only store a single word — even if you type many words:

string fullName;
cout << "Type your full name: ";
cin >> fullName;
cout << "Your name is: " << fullName;
Interactive session
Type your full name: John Doe Your name is: John

From the example above, you would expect the program to print "John Doe", but it only prints "John". That's why, when working with strings, we often use the getline() function to read a line of text. It takes cin as the first parameter, and the string variable as second:

string fullName;
cout << "Type your full name: ";
getline(cin, fullName);      // reads the whole line, spaces included
cout << "Your name is: " << fullName;
Interactive session
Type your full name: John Doe Your name is: John Doe
🧨 The leftover-newline trap

Mixing cin >> and getline is the single most common beginner input bug. cin >> age leaves the '\n' in the buffer; the next getline immediately reads that empty line.

int age;
string name;

cin >> age;                     // user types "25\n" → buffer holds '\n'
cin.ignore();                   // ✓ consume the leftover newline
getline(cin, name);             // now reads the real name

⚠️ Integer division truncates

When dividing two integers in C++, the result will also be an integer. For example, 10 / 3 gives 3 — the decimal part is discarded (not rounded). If you want a decimal result, use float or double values, like 10.0 / 3.

5.8 Operator Precedence

When a calculation contains more than one operator, C++ follows order of operations rules to decide which part to calculate first. For example, multiplication happens before addition:

int result1 = 2 + 3 * 4;      // 2 + 12 = 14
int result2 = (2 + 3) * 4;    // 5 * 4 = 20

cout << result1 << "\n";
cout << result2 << "\n";
Output
14 20

If you want the addition to happen first, you must use parentheses: (2 + 3) * 4 gives 20.

Order of operations (highest to lowest)

  1. () — Parentheses
  2. *, /, % — Multiplication, Division, Modulus
  3. +, - — Addition, Subtraction
  4. >, <, >=, <= — Comparison
  5. ==, != — Equality
  6. && — Logical AND
  7. || — Logical OR
  8. = — Assignment

Subtraction and addition are done from left to right, unless you add parentheses:

int result1 = 10 - 2 + 5;      // (10 - 2) + 5 = 13
int result2 = 10 - (2 + 5);    // 10 - 7 = 3

cout << result1 << "\n";
cout << result2 << "\n";
Output
13 3
💡 Always use parentheses when in doubt

Parentheses always come first. Use them to control the order of your calculations — they also make your code easier to read.

6.3 Numbers and Strings — A Warning

⚠️ C++ uses + for both addition and concatenation

Numbers are added. Strings are concatenated. This is a common source of confusion for beginners.

If you add two numbers, the result will be a number:

int x = 10;
int y = 20;
int z = x + y;    // z will be 30 (an integer)

If you add two strings, the result will be a string concatenation:

string x = "10";
string y = "20";
string z = x + y;    // z will be "1020" (a string)

If you try to add a number to a string, an error occurs:

string x = "10";
int y = 20;
string z = x + y;    // ✗ Error: cannot add string and int directly

To fix this, convert the number to a string first with std::to_string:

string x = "10";
int y = 20;
string z = x + to_string(y);    // ✓ z = "1020"

7. Booleans & Conditions

7.1 The bool Type

Boolean values are either true or false.

7.2 The if Statement

Use the if statement to specify a block of C++ code to be executed if a condition is true:

if (condition) {
    // block of code to be executed if the condition is true
}

Note: if is in lowercase letters. Uppercase letters (If or IF) will generate an error.

In the example below, we test two values to find out if 20 is greater than 18. If the condition is true, print some text:

if (20 > 18) {
    cout << "20 is greater than 18";
}
Output
20 is greater than 18

We can also test variables:

int x = 20;
int y = 18;

if (x > y) {
    cout << "x is greater than y";
}
Output
x is greater than y

In the example above, we use two variables, x and y, to test whether x is greater than y. As x is 20, and y is 18, and we know that 20 is greater than 18, we print to the screen that "x is greater than y".

7.3 The else Statement

Use the else statement to specify a block of code to be executed if the condition is false:

if (condition) {
    // block of code if condition is true
} else {
    // block of code if condition is false
}
int time = 20;

if (time < 18) {
    cout << "Good day.";
} else {
    cout << "Good evening.";
}
// Outputs "Good evening."
Output
Good evening.

In the example above, time (20) is greater than 18, so the condition is false. Because of this, we move on to the else condition and print "Good evening". If the time was less than 18, the program would print "Good day".

7.4 The else if Statement

Use the else if statement to specify a new condition if the first condition is false:

if (condition1) {
    // block if condition1 is true
} else if (condition2) {
    // block if condition1 is false AND condition2 is true
} else {
    // block if condition1 is false AND condition2 is false
}
int time = 22;

if (time < 10) {
    cout << "Good morning.";
} else if (time < 20) {
    cout << "Good day.";
} else {
    cout << "Good evening.";
}
// Outputs "Good evening."
Output
Good evening.

In the example above, time (22) is greater than 10, so the first condition is false. The next condition, in the else if statement, is also false, so we move on to the else condition since condition1 and condition2 are both false — and print "Good evening". However, if the time was 14, our program would print "Good day."

📘 Order matters

The chain stops at the first true condition. Writing if (score >= 70) before if (score >= 90) would make "A" unreachable. Always order from most restrictive to least restrictive.

7.5 Short Hand If...Else (Ternary Operator)

There is also a short-hand if...else, known as the ternary operator because it uses three operands. The ternary operator returns a value based on a condition: if the condition is true, it returns the first value; otherwise, it returns the second value.

It can be used to replace multiple lines of code with a single line, and is often used to replace simple if...else statements:

variable = (condition) ? expressionTrue : expressionFalse;

Instead of writing:

int time = 20;
if (time < 18) {
    cout << "Good day.";
} else {
    cout << "Good evening.";
}

You can simply write:

int time = 20;
string result = (time < 18) ? "Good day." : "Good evening.";
cout << result;

Or even inside cout directly:

int time = 20;
cout << ((time < 18) ? "Good day." : "Good evening.");
Output
Good evening.

Nested ternary (optional)

You can nest ternary operators to handle more than two outcomes, but it can make your code harder to read:

int time = 22;
string message = (time < 12) ? "Good morning."
               : (time < 18) ? "Good afternoon."
               : "Good evening.";
cout << message;
💡 Use the ternary operator wisely

Use the ternary operator for short and simple conditions. For longer or more complex logic, the regular if...else statement is easier to read.

7.6 Nested If

You can also place an if statement inside another if. This is called a nested if statement. A nested if lets you check for a condition only if another condition is already true:

if (condition1) {
    // code to run if condition1 is true
    if (condition2) {
        // code to run if both condition1 and condition2 are true
    }
}
int x = 15;
int y = 25;

if (x > 10) {
    cout << "x is greater than 10\n";
    if (y > 20) {
        cout << "y is also greater than 20\n";
    }
}
Result
x is greater than 10 y is also greater than 20

You can nest as many if statements as you want, but avoid making the code too deep — it can become hard to read. Nested if is often used together with else and else if for more complex decisions.

7.7 Logical Operators in Conditions

You can combine or reverse conditions using logical operators. These work together with if, else, and else if to build more complex decisions.

  • && (AND) — all conditions must be true
  • || (OR) — at least one condition must be true
  • ! (NOT) — reverses a condition (true → false, false → true)

AND (&&)

Use AND (&&) when both conditions must be true. Test if a is greater than b, and if c is greater than a:

int a = 200;
int b = 33;

    cout << "Both conditions are true";
}
Output
Both conditions are true

OR (||)

Use OR (||) when at least one of the conditions can be true. Test if a is greater than b, or if a is greater than c:

int a = 200;
int b = 33;

    cout << "At least one condition is true";
}
Output
At least one condition is true

The NOT operator (!) reverses a condition. If a condition is true, ! makes it false. If a condition is false, ! makes it true. This is useful when you want to check that something is not the case:

8. Switch Statements

Use the switch statement to select one of many code blocks to be executed. It compares one integral or enum value against a list of compile-time constants. It is clearer and often faster (jump table) than a long if-else if chain.

switch (expression) {
    case x:
        // code block
        break;
    case y:
        // code block
        break;
    default:
        // code block
}

This is how it works:

  • The switch expression is evaluated once.
  • The value of the expression is compared with the values of each case.
  • If there is a match, the associated block of code is executed.
  • The break and default keywords are optional, and will be described later in this chapter.

8.1 Weekday Example

The example below uses the weekday number to calculate the weekday name:

int day = 4;

switch (day) {
    case 1: cout << "Monday";    break;
    case 2: cout << "Tuesday";   break;
    case 3: cout << "Wednesday"; break;
    case 4: cout << "Thursday";  break;
    case 5: cout << "Friday";    break;
    case 6: cout << "Saturday";  break;
    case 7: cout << "Sunday";    break;
}
// Outputs "Thursday" (day 4)
Output
Thursday

8.2 The break Keyword

When C++ reaches a break keyword, it breaks out of the switch block. This will stop the execution of more code and case testing inside the block. When a match is found, and the job is done, it's time for a break. There is no need for more testing.

A break can save a lot of execution time because it "ignores" the execution of all the rest of the code in the switch block.

Without break — fall-through

Without break, control falls through into the next case and keeps executing:

int x = 1;
switch (x) {
    case 1: cout << "one ";     // no break!
    case 2: cout << "two ";     // no break!
    case 3: cout << "three ";   break;
}
cout << "\n";
Output
one two three

Fallthrough is occasionally useful (grouping cases). When intentional, mark it explicitly with [[fallthrough]];.

8.3 The default Keyword

The default keyword specifies some code to run if there is no case match:

int day = 4;

switch (day) {
    case 6: cout << "Today is Saturday"; break;
    case 7: cout << "Today is Sunday";   break;
    default: cout << "Looking forward to the Weekend";
}
// Outputs "Looking forward to the Weekend"
Output
Looking forward to the Weekend

9. Loops

Loops can execute a block of code as long as a specified condition is reached. Loops are handy because they save time, reduce errors, and make code more readable. Loops are used to repeat actions without writing the same code many times.

9.1 while Loop — Check First, Then Run

A while loop checks the condition before repeating.

while (condition) {
    // code block to be executed
}

In the example below, the code in the loop will run, over and over again, as long as a variable (i) is less than 5:

int i = 0;
while (i < 5) {
    cout << i << "\n";
    i++;
}
Output
0 1 2 3 4
⚠️ Do not forget to increase the variable

Do not forget to increase the variable used in the condition (i++), otherwise the loop will never end — an infinite loop.

📘 Why i?

Do you wonder why we use the letter i as a variable name? It's a counter variable and a common choice in simple loops because it's short, traditional, and stands for "index" or "iterator".

9.6 do-while Loop — Run First, Then Check

The do/while loop is a variant of the while loop. This loop will execute the code block once, before checking if the condition is true. Then it will repeat the loop as long as the condition is true.

do {
    // code block to be executed
} while (condition);   // NOTE the semicolon
⚠️ The semicolon after while is required!

The do-while loop is the only loop in C++ that ends with a ; after the while (condition). Forgetting it produces a compile error.

Standard example

int i = 0;
do {
    cout << i << "\n";
    i++;
} while (i < 5);
Output
0 1 2 3 4

Do not forget to increase the variable used in the condition (i++), otherwise the loop will never end!

Condition is false from the start

In the example above, the condition i < 5 was true at the beginning, so the loop executed multiple times. But what if the condition is false right from the start?

In the example below, the variable i starts at 10, so the condition i < 5 is false immediately — yet the do/while loop still runs once:

int i = 10;
do {
    cout << "i is " << i << "\n";
    i++;
} while (i < 5);
Output
i is 10
📘 The key difference

The do/while loop always runs at least once, even if the condition is already false. This is different from a regular while loop, which would skip the loop entirely if the condition is false at the start.

This behavior makes do/while useful when you want to ensure something happens at least once, like showing a message or asking for user input.

Practical example: user input

This example keeps asking the user to enter a positive number. The loop stops when the user enters 0 or a negative number:

int number;
do {
    cout << "Enter a positive number: ";
    cin >> number;
} while (number > 0);

9.7 for Loop — When You Know the Count

When you know exactly how many times you want to loop through a block of code, use the for loop instead of a while loop:

for (statement 1; statement 2; statement 3) {
    // code block to be executed
}
  • Statement 1 is executed (one time) before the execution of the code block.
  • Statement 2 defines the condition for executing the code block.
  • Statement 3 is executed (every time) after the code block has been executed.

Print numbers 0 to 4:

Explanation:

continue

The continue statement breaks one iteration (in the loop), if a specified condition occurs, and continues with the next iteration in the loop.

This example skips the value of 4:

Break and continue in while loops

    cout << i << "\n";

0 1 2 3

Continue in a while loop

⚠️ Careful with continue in while loops

In a while loop, if you use continue before the increment, you create an infinite loop. Put the increment before continue:

int i = 0;
while (i < 10) {
    if (i == 4) {
        i++;              // ← must increment BEFORE continue
        continue;
    }
    cout << i << "\n";
    i++;
}

10. Arrays & Vectors

10.1 What is an Array?

Arrays are used to store multiple values in a single variable, instead of declaring separate variables for each value. An array stores multiple values of the same type in one variable.

To declare an array, define the variable type, specify the name of the array followed by square brackets, and specify the number of elements it should store:

string cars[4];

We have now declared a variable that holds an array of four strings. To insert values into it, we can use an array literal — place the values in a comma-separated list, inside curly braces:

string cars[4] = {"Volvo", "BMW", "Ford", "Mazda"};

To create an array of three integers, you could write:

int myNum[3] = {10, 20, 30};

10.2 Access the Elements of an Array

You access an array element by referring to the index number inside square brackets [].

string cars[4] = {"Volvo", "BMW", "Ford", "Mazda"};
cout << cars[0];   // Outputs Volvo
Output
Volvo

Note: Array indexes start with 0: [0] is the first element, [1] is the second element, etc.

Figure 4 — Arrays live contiguously in memory. Index 0 is the first element; each successive element is sizeof(type) bytes further along.

10.3 Change an Array Element

To change the value of a specific element, refer to the index number:

string cars[4] = {"Volvo", "BMW", "Ford", "Mazda"};
cars[0] = "Opel";
cout << cars[0];
// Now outputs Opel instead of Volvo
Output
Opel
🧨 Out-of-bounds access is undefined behavior
int a[5];
a[5]  = 10;   // ✗ past the end — UB
a[-1] = 20;   // ✗ before the start — UB

C++ does not check array bounds. This is the source of countless security vulnerabilities in real software.

11.7 Pass by Value vs Pass by Reference — Critical

📘 Think of it like… photocopy vs original

Passing by value is handing over a photocopy — the function can scribble on it but your original is safe. Passing by reference is handing over the original document — whatever the function writes goes straight into your copy.

void writeOnCopy(int x)  { x = 999; }   // photocopy → original unchanged
void writeOriginal(int& x) { x = 999; }   // original → variable becomes 999

int score = 10;
writeOnCopy(score);   // score is still 10
writeOriginal(score); // score is now 999

Rule of thumb: small read-only params → by value; large read-only params → by const&; must-modify params → by non-const &.

11.8 Scope

Scope is the region in which a variable can be used.

  • Local variables exist inside a function — they die at the closing brace.
  • Global variables exist outside all functions — they live for the program's entire lifetime.
int globalVar = 100;          // global scope

void demo() {
    int localVar = 10;        // local scope
    {
        int inner = 5;         // block scope
        cout << inner << "\n";
    }
    // cout << inner;   // ✗ ERROR: out of scope
}
⚠️ Avoid global variables

Globals can be modified from anywhere, which makes bugs extremely hard to trace. Prefer passing data as parameters and returning results. Reserve globals for genuine program-wide constants (constexpr).

11.9 Recursion

Recursion is when a function calls itself. Every recursive function needs a base case — without it, you get a stack overflow.

Example: Factorial

int factorial(int n) {
    if (n == 1) return 1;          // base case
    return n * factorial(n - 1);       // recursive case
}

cout << factorial(10) << "\n";          // 3628800
Output
3628800

Tracing factorial(4):

4 * factorial(3)
4 * 3 * factorial(2)
4 * 3 * 2 * factorial(1)
4 * 3 * 2 * 1 = 24
🧨 Missing base case
int bad(int n) { return bad(n - 1); }   // ✗ infinite recursion → crash

12.1 The Memory Model

Figure 6 — Where your variables live. Knowing which region a variable lives in explains why local variables "disappear" (stack unwinds) and why forgetting delete leaks memory (heap never shrinks).

12.2 References

A reference is another name for the same variable. It must be initialized when declared and can never be rebound.

int x = 10;
int &ref = x;    // ref IS x

ref = 20;

cout << &x    << "\n";       // same address

12.3 Pointers

A pointer stores the memory address of another variable. Two operators matter:

  • &x — address-of: gives the address of x.
  • *p — dereference: gives the value stored at the address in p.
int x = 10;
int *p = &x;     // p stores the address of x

cout << x     << "\n";   // 10
cout << p     << "\n";   // address
cout << *p    << "\n";   // 10
Output
10 0x7ffd3e2a1b4c 10

Changing a value through a pointer

*p = 50;
cout << x;    // 50
Output
50

Pointers can move through array elements:

int arr[3] = {10, 20, 30};

cout << *(ptr + 1) << "\n";   // 20

12.5 Swap Using References

void swapValues(int &a, int &b) {
    int temp = a;
    a = b;
    b = temp;
}

int x = 1, y = 2;
swapValues(x, y);   // now x=2, y=1

12.6 Dynamic Memory: new and delete

Dynamic memory is memory allocated while the program is running. The new operator allocates; delete frees.

// Single object
int *p = new int;
*p = 25;
cout << *p << "\n";   // 25
delete p;              // free the memory
p = nullptr;           // good hygiene

// Dynamic array
int *arr = new int[5];
arr[0] = 10;
arr[1] = 20;
delete[] arr;           // NOTE the []
⚠️ The three classic memory bugs
  • Memory leak: new without delete — memory is never returned.
  • Dangling pointer: using a pointer after delete.
  • Double free: calling delete twice on the same pointer.

12.7 Smart Pointers — The Modern Solution

Smart pointers own heap memory and free it automatically. This is how modern C++ handles dynamic memory.

#include <memory>

{
    auto p = std::make_unique<int>(42);
    cout << *p << "\n";
}   // memory freed automatically here — no delete needed

auto a = std::make_shared<string>("shared");
auto b = a;                    // reference count = 2
cout << a.use_count() << "\n"; // 2

13.7 Complete Bank Account Class

#include <iostream>
#include <string>
#include <vector>
#include <stdexcept>
using namespace std;

class BankAccount {
private:
    string         owner;
    double         balance;
    vector<string> history;

    void log(const string& entry) { history.push_back(entry); }

public:
    BankAccount(string o, double initial = 0.0)
        : owner{o}, balance{initial} {
        if (initial < 0) throw invalid_argument("Negative initial balance");
        log("Account opened");
    }

    double getBalance() const { return balance; }
    const string& getOwner() const { return owner; }

    void deposit(double amount) {
        if (amount <= 0) throw invalid_argument("Deposit must be positive");
        balance += amount;
        log("Deposit: " + to_string(amount));
    }

    bool withdraw(double amount) {
        if (amount <= 0) throw invalid_argument("Withdrawal must be positive");
        if (amount > balance) return false;
        balance -= amount;
        log("Withdrawal: " + to_string(amount));
        return true;
    }

    void printHistory() const {
        cout << "--- " << owner << "'s history ---\n";
        for (const string& h : history) cout << "  " << h << "\n";
        cout << "Balance: $" << balance << "\n";
    }
};

int main() {

16.12 Why C++ Specifically?

Three properties explain almost every item in the lists above:

  1. Zero-cost abstractions. A C++ class or template compiles to code as fast as hand-written C.

B.3 Debugging Strategies

  • Reproduce reliably. A bug you cannot reproduce cannot be fixed.
  • Bisect. Comment out half the code; narrow down which half contains the bug.
  • Print early, print often. Temporary cout statements remain the fastest debugging tool.
  • Check assumptions. The bug is almost always where you were certain there was none.
  • Read the error bottom-up. Compiler errors often list the root cause last.

Appendix D — Best Practices Checklist

D.1 Variables & Types

  • Initialize every variable at the point of declaration.
  • Prefer brace initialization int x{5}; — it blocks narrowing.
  • Use const for values that never change; constexpr for compile-time constants.
  • Use double rather than float unless memory is genuinely constrained.
  • Never compare floating-point values with ==.
  • Use size_t for sizes and indices.

D.2 Control Flow

  • Always use braces, even for single-statement bodies.
  • Order if-else if chains from most to least restrictive.
  • Never forget break in a switch.
  • Prefer range-based for when iterating whole containers.
  • Guard loop bounds: use i < size, never i <= size.

D.3 Functions

  • Keep functions small and single-purpose.
  • Pass large objects by const&.
  • Mark read-only member functions const.
  • Avoid global mutable state.
  • Use nullptr, never NULL or 0.

D.4 Memory & Resources

  • Prefer std::vector / std::string over raw arrays.
  • Never write new/delete — use smart pointers.
  • Follow RAII: let destructors release resources.
  • Give polymorphic base classes a virtual destructor.
  • Compile with sanitizers during development.

D.5 Code Quality

  • Compile with -Wall -Wextra -Werror; fix all warnings.
  • Use names that describe meaning, not type.
  • Comment the why, not the what.
  • Keep functions and variables as local in scope as possible.
  • Format consistently (use clang-format).
